# Pokemon Battle System

### Object-Oriented Programming & Data Structures in Java

A Java project implementing a Pokémon management and battle system using object-oriented programming principles, custom data structures, inheritance, comparators, and exception handling.

## Project Overview

The system manages Pokémon, Pokémon types, and a Pokédex using custom tree and forest data structures.

The project focuses on designing and integrating object-oriented classes with custom data structures while supporting different Pokémon types, specialized Pokémon behavior, sorting, and exception handling.

## Data Structures

### Tree

A custom tree implementation is used to organize and manage Pokémon data in a hierarchical structure.

### Forest

A custom forest implementation manages a collection of trees and provides operations for working with multiple Pokémon structures.

## Object-Oriented Design

### Pokémon Classes

The project uses `Pokemon` as a core class for representing Pokémon, with `SpecialPokemon` providing specialized Pokémon behavior through inheritance.

### Pokémon Types

The `Type` class represents different Pokémon types and their associated properties.

### Comparators

Custom comparators are implemented for ordering Pokémon according to different criteria:

* **PokemonTypeComparator** – compares Pokémon based on their type.
* **PokemonCalcAttackComparator** – compares Pokémon based on calculated attack values.

## Project Structure

* **Pokemon** – Pokémon data and functionality
* **SpecialPokemon** – specialized Pokémon implementation
* **Pokedex** – Pokémon collection management
* **MyTree** – custom tree data structure
* **MyForest** – custom forest data structure
* **Type** – Pokémon type definitions
* **PokemonTypeComparator** – type-based Pokémon comparison
* **PokemonCalcAttackComparator** – attack-based Pokémon comparison
* **PokemonException** – custom exception handling
* **Assignment7Tests / OpenAssignment7Test** – provided test files
